# AI-Notes

Every working document from the AI-assisted arcs lives here, off the
suite root. The root keeps only the three living docs: `README.md`
(build/run/test), `GETTING_STARTED_DEV.md` (fresh-machine developer
route), `CLAUDE.md` (AI instance guide).

Sub-sections:

- `plans/`        `*_PLAN.md` + roadmaps — the phased plan for an arc
                  (phases, decisions, open questions, grounding index)
- `handoffs/`     `*_HANDOFF.md` / handovers / cross-instance requests —
                  session-to-session state for an arc in flight
- `evaluations/`  adopt-or-not findings: library options, licence
                  gates, audits, governance reviews
- `designs/`      design/spec documents (page designs, capability
                  contracts, practice maps)
- `ledgers/`      living lists that accumulate: TESTING_OWED,
                  FRONTEND_WORK_MAP, missing-data ledgers
- `guides/`       walkthrough guides (home-network access test, run
                  notes)

Older references to "<X>_PLAN.md at suite root" or "AI-Plans/<X>" mean
`AI-Notes/plans/<X>_PLAN.md` now (same for the other kinds).
