# AI-Plans

Every arc's plan, handoff, roadmap, and evaluation document lives here
(they used to crowd the suite root). Naming convention:

- `*_PLAN.md`       the phased plan for an arc (phases, decisions,
                    open questions, grounding index)
- `*_HANDOFF.md`    session-to-session handoff for an arc in flight
- `*_ROADMAP.md` / `*_EVALUATION.md`   longer-horizon direction /
                    adopt-or-not findings

The suite root keeps only the living operational docs: `README.md`
(build/run/test), `GETTING_STARTED_DEV.md` (fresh-machine developer
route), `CLAUDE.md` (AI instance guide), and working ledgers like
`TESTING_OWED.md` / `FRONTEND_WORK_MAP.md`.
